# Bayut QA Agentic System — Project Brief

Agentic black-box QA for the **Bayut UAE Android app**, owned by the manual QA team at
Dubizzle Labs. This file loads on every session — treat it as binding.

**New session? Read `docs/PROJECT-STATE.md` first.** It says what is built, what is not,
what is blocked, and what the next action is. Do not infer project status from the file
tree — half of what looks present is a hypothesis awaiting verification.

## Hard constraints

1. **No source code access.** Everything is black-box: UI, network, logs, store data.
   Never write anything that assumes reading the Bayut app repo. Independence from the
   dev codebase is the value we provide, not a gap to close.
2. **Agents never file tickets.** Every defect is an *unverified Markdown report* under
   `reports/`. A human reviews it and logs it in ClickUp manually. `clickup_client.py`
   is read-only by construction and must stay that way.
3. **Nothing leaves the system without a human gate.** Test cases go to Testmo as
   **drafts**. Healed locators are **diffs for review**. Bug reports are **proposals**.
4. **Evidence over inference.** If a claim cannot be evidenced from an artifact actually
   read, write `UNKNOWN — needs manual verification`. Never guess.
5. **Determinism in Python, judgment in the model.** If being wrong would be *invisible*,
   it goes in `tools/`. Combinatorics, log trimming, HAR filtering, set diffing and
   coverage math are code. Never ask a model to enumerate a covering array.
6. **Fail loud.** No silent retries. No auto-healing that masks a regression.
7. **If evidence contradicts the test's own assertion, it is a TEST DEFECT, not a bug.**

## Driving the live app — non-negotiable

The app is production, signed in with a real test account. Tapping a contact-agent
control **sends a real lead to a real Dubai agency**: real money, real relationship
damage, and the one mistake that ends this programme.

- Every tap in `crawler.py` and `prober.py` goes through `crawl_safety.SafetyPolicy`.
  There is no second tap path and no flag that disables the blocklist.
- Run `python tools/crawl_safety.py selftest` before every crawl session. Must be 65/65.
- STRICT by default: an element matching no allow rule is logged, not tapped.
- Screenshot before every tap. Max 1 action / 800ms. Hard stop at 400 actions.
- Uncertain? Do not tap. A missed screen is cheap; a hundred spurious leads is not.
- Report certificate pinning within 5 minutes of the first crawl, not at the end.

## Tools

**Context-building (Phase 0.5) — built and verified offline.**

| Script | Responsibility |
|---|---|
| `tools/pagesource.py` | Parse/fingerprint UiAutomator dumps. Structural fingerprint = resource-ids only, so it is locale-invariant. |
| `tools/crawl_safety.py` | **Tap guard.** Default-deny. Block always beats allow. `selftest` before every session. |
| `tools/adb.py` | Devices, reset, locale, deep links, proxy, logcat, screenrecord, dumpsys. `--dry-run` works with no device. |
| `tools/crawler.py` | PASSIVE crawl → screen/element inventory, screen graph, locator quality, listing-ID visibility, blocked/uncertain logs. |
| `tools/prober.py` | PROBE P1–P7 → filter behaviour from result-count deltas, raw counts always recorded. |

**Execution (Phase 1) — NOT built yet.** `testmo_client.py`, `clickup_client.py`,
`evidence.py`, `pairwise.py`, `oracle.py`, `har_diff.py`. The last two deliberately wait
on the first crawl: it decides whether the API is interceptable and whether exact
listing-ID matching is possible.

## Conventions for anything written here

- `context/` files are **outputs of `app-cartographer`**. Confirmed lines are tagged
  `[OBSERVED <date> build <n>]`; unconfirmed ones `[ASSUMED — verify]` or `[UNRESOLVED]`.
- No `sleep()` in test code. Explicit waits only.
- Locator priority: `accessibility id` → `resource-id` → `uiautomator` → XPath last, and
  log a warning on every XPath use so fragility stays visible.
- Secrets and machine-specific values go in `.env`, referenced by name. Never inline a
  token, device serial, account, package name, or host.
- `com.bayut.app` appearing anywhere is a **placeholder**, not a verified package name.
- Record every non-obvious design choice in `docs/DECISIONS.md` with its rationale.
- Every tool ships a `selftest` or a fixture-based offline mode. Prove it there first.
- Say plainly when something cannot be automated or when an ask will likely be refused.
