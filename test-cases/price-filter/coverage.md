the arithmetic (4 frequencies × 1 + 1), so no real combination has been silently deleted.

### Band definitions

`price_band` is symbolic in the model so the array stays currency-agnostic. Concrete
values when executing:

| Band | Rent (Yearly) | Buy |
|---|---|---|
| `none` | untouched — min `0`, max `Any` | untouched |
| `low` | 0 – 40,000 | 0 – 500,000 |
| `mid` | 80,000 – 120,000 | 1,000,000 – 2,000,000 |
| `high` | 300,000 – `Any` | 10,000,000 – `Any` |
| `inverted` | 120,000 – 80,000 | 2,000,000 – 1,000,000 |
| `zero_max` | 0 – 0 | 0 – 0 |

`[ASSUMED — needs verification]` — bands are chosen to be plausible for Dubai inventory,
not observed from it. They affect only whether a row returns results, never whether the
filter is correct.
